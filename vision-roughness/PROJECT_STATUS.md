# RoughSense 锐感视觉 — 项目状态报告

> **项目全称**：基于机器视觉的 EDM 表面粗糙度分类与尺寸检测系统  
> **项目代号**：RoughSense（锐感视觉）  
> **报告日期**：2026-07-20（更新：ResNet18 v2 复训达标）  
> **当前阶段**：阶段四完成（模型对比已定），等待硬件到位进入阶段五

---

## 一、项目目标

通过工业相机拍摄 EDM（电火花加工）工件表面图像，利用机器学习/深度学习模型完成：

1. **粗糙度分级**：将工件按表面纹理分为 16 个等级（对应不同加工参数/角度）
2. **OK/NG 判定**：根据 Ra 分界值将 16 分类映射为合格/不合格（不输出 Ra 数值）
3. **尺寸测量**：通过相机标定 + 边缘检测，测量工件关键尺寸并判定公差

## 四、模型训练结果

### 4.1 Baseline A：GLCM + SVM

| 指标 | 数值 |
|---|---|
| 特征 | GLCM 纹理（10维）+ 灰度统计（4维）= 14维 |
| 分类器 | SVM (RBF kernel, C=10) + StandardScaler |
| 训练集/测试集 | 3456 / 864 |
| **测试准确率** | **88.00%**（训练时划分）/ **89.93%**（全量评估） |
| 推理速度 | 167.4 ms/张（CPU） |
| 模型大小 | 586 KB |
| 模型文件 | `models/v1_glcm_svm_20260718_1245.pkl` |

**各类表现**：
- 强项：class_04/05/06/07/08 准确率 96~100%
- 弱项：class_14 (70%)、class_15 (65%) — 相邻角度纹理相似导致混淆

### 4.2 Baseline B：ResNet18 迁移学习

| 指标 | 数值 |
|---|---|
| 基础模型 | ImageNet 预训练 ResNet18 |
| 修改 | 最后全连接层 → 16 类 |
| 训练参数 | Epochs=15, LR=1e-4, Batch=32, 数据增强 |
| 设备 | RTX 5060 Laptop GPU (CUDA 12.9) |
| **最佳测试准确率** | **94.91%** |
| 推理速度 | 26.3 ms/张（GPU） |
| 模型大小 | 42.7 MB |
| 模型文件 | `models/resnet18.pth` + `models/class_to_idx.json` |

**训练过程**：
- Epoch 1: 84.49% → Epoch 4: 92.13% → Epoch 14: 94.91%（最佳）
- 收敛快，GPU 训练仅 ~3 分钟

#### v2 复训（2026-07-20，当前在用模型）

修复了 v1"测试集当验证集用"的方法学问题，测试准确率现在是无偏估计：

| 指标 | 数值 |
|---|---|
| 训练参数 | Epochs=30, LR=1e-4, Batch=32 |
| 数据划分 | 训练 3111 / 验证 345 / 测试 864（72%/8%/20%） |
| 选模依据 | 验证集准确率（测试集只在最后评估一次） |
| 最佳验证准确率 | 93.91% |
| **测试准确率** | **95.60%** ✅ 达到 ≥95% 验收线 |
| 模型文件 | `models/resnet18.pth`（v1 备份为 `models/resnet18_v1_9491.pth`） |

### 4.3 模型对比

| 指标 | GLCM+SVM | ResNet18 | 胜出 |
|---|---|---|---|
| 准确率 | 89.93% | **94.91%** | ResNet |
| 推理速度 | 167.4ms/张 | **26.3ms/张** | ResNet (6.4x) |
| 模型大小 | **586KB** | 42.7MB | GLCM |
| GPU 需求 | **不需要** | 需要 | GLCM |
| 可解释性 | **高** | 低 | GLCM |

### 4.4 选型结论

**生产环境选用 ResNet18**，理由：
1. 准确率显著更高，v2 复训后达 95.60%，满足 ≥95% 目标
2. GPU 推理速度反而更快（26ms vs 167ms）
3. 42.7MB 模型大小在工业场景完全可接受
4. GLCM+SVM 保留为离线备份和对照基线

## 九、风险与注意事项

1. **开源数据 vs 实际数据差距**：当前 95.60% 是基于 Kaggle 数据，实际工况（光照、对焦、污染）可能导致精度下降
2. **sklearn 版本警告**：GLCM 模型用 sklearn 1.3.2 训练，当前环境 1.9.0，功能正常但有警告。如需消除可重训
3. **数据不均衡**：class_15/16 各 480 张（其他 240 张），训练时已自动处理
4. **Windows 多进程**：DataLoader 需设 `num_workers=0`，避免 Windows spawn 模式报错
